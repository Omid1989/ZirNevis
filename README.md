# ZirNevis | زیرنویس

**ZirNevis** یک برنامه اندرویدی برای تبدیل گفتار انگلیسی به زیرنویس فارسی به‌صورت **زنده و آفلاین** است.

این برنامه صدای داخلی دستگاه را دریافت می‌کند، گفتار انگلیسی را روی خود دستگاه به متن تبدیل می‌کند و سپس متن را به فارسی ترجمه می‌کند. نتیجه به‌صورت یک **زیرنویس شناور روی سایر برنامه‌ها** نمایش داده می‌شود.

> 🎧 صدای داخلی دستگاه  
> 🗣️ گفتار انگلیسی  
> 📝 تبدیل گفتار به متن  
> 🌐 ترجمه انگلیسی به فارسی  
> 📱 نمایش زیرنویس روی برنامه‌های دیگر  
> 🔒 پردازش روی دستگاه و بدون نیاز به اینترنت

---

## ✨ امکانات

- تبدیل زنده گفتار انگلیسی به متن
- ترجمه خودکار انگلیسی به فارسی
- نمایش زیرنویس به‌صورت Overlay روی سایر برنامه‌ها
- پردازش گفتار و ترجمه به‌صورت **On-Device**
- امکان استفاده بدون اتصال اینترنت پس از دانلود مدل‌ها
- استفاده از **صدای داخلی دستگاه** به‌جای میکروفون
- مناسب برای فیلم، ویدئو، کلاس‌های آنلاین و سایر محتوای انگلیسی

---

## 🔒 حریم خصوصی

ZirNevis برای پردازش اصلی خود به سرویس ابری وابسته نیست.

پردازش گفتار و ترجمه روی خود دستگاه انجام می‌شود و صدای دریافت‌شده برای انجام این پردازش به سرور خارجی ارسال نمی‌شود.

**توجه:** برنامه از صدای داخلی دستگاه استفاده می‌کند و برای دریافت صدای محتوای در حال پخش، از قابلیت Audio Playback Capture اندروید استفاده می‌کند.

---

## 🤖 هوش مصنوعی

ZirNevis از مدل‌های هوش مصنوعی اجراشونده روی دستگاه برای دو مرحله اصلی استفاده می‌کند:

### 1. Speech-to-Text

برای تبدیل گفتار انگلیسی به متن از مدل‌های **Sherpa-ONNX** استفاده می‌شود.

پردازش به‌صورت محلی روی دستگاه انجام می‌شود و برای تبدیل گفتار به متن نیازی به ارسال صدا به سرویس ابری نیست.

### 2. English → Persian Translation

برای ترجمه متن انگلیسی به فارسی، یک مدل **Marian** به‌صورت اختصاصی برای این پروژه آموزش داده شده است.

این مدل با استفاده از داده‌های انگلیسی و فارسی و با هدف استفاده در ترجمه **English → Persian** توسعه داده شده و برای اجرای محلی در ZirNevis به فرمت ONNX تبدیل شده است.

**مدل آموزش‌دیده:**

[Marian English → Persian – Hugging Face](https://huggingface.co/omid1989ahmadi/marian-en-fa)

این مدل به‌صورت مستقل در Hugging Face منتشر شده است.

---

## 🧠 مدل ترجمه Marian

| مشخصات | مقدار |
|---|---|
| Architecture | MarianMT |
| Direction | English → Persian |
| Tokenizer | MarianTokenizer |
| Vocabulary | 32,000 tokens |
| Training Data | English–Persian parallel data |
| هدف | ترجمه آفلاین و اجرای محلی |
| استفاده در ZirNevis | بله |
| Hugging Face | [omid1989ahmadi/marian-en-fa](https://huggingface.co/omid1989ahmadi/marian-en-fa) |

مدل اصلی در Hugging Face شامل فایل‌های موردنیاز برای استفاده از مدل Marian است و نسخه ONNX آن برای اجرای بهینه در محیط Android استفاده می‌شود.

## ⚠️ نکات مهم

- تشخیص گفتار فعلاً برای **زبان انگلیسی** طراحی شده است.
- ترجمه فعلاً در مسیر **English → Persian** انجام می‌شود.
- کیفیت تبدیل گفتار به متن به کیفیت صدای ورودی و سخت‌افزار دستگاه بستگی دارد.
- اجرای مدل‌های هوش مصنوعی روی دستگاه به CPU و RAM نیاز دارد.
- مدل‌های موردنیاز می‌توانند فضای قابل‌توجهی از حافظه دستگاه را مصرف کنند.
- قابلیت دریافت صدای داخلی به نسخه Android و پشتیبانی دستگاه از Audio Playback Capture وابسته است.
- برخی برنامه‌ها ممکن است اجازه Capture شدن صدای داخلی خود را ندهند.
