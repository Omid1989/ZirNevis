# ZirNevis | زیرنویس

**زیرنویس زنده انگلیسی به فارسی، مستقیم روی دستگاه شما**

</div>

---

<div dir="rtl" align="right">

**ZirNevis** یک برنامه اندرویدی برای تبدیل گفتار انگلیسی به زیرنویس فارسی به‌صورت **زنده و آفلاین** است. برنامه صدای داخلی دستگاه را دریافت می‌کند، گفتار را به متن تبدیل می‌کند، متن را به فارسی ترجمه می‌کند و نتیجه را به‌صورت **زیرنویس شناور روی سایر برنامه‌ها** نمایش می‌دهد.

هدف پروژه، فراهم کردن راهی ساده برای تماشای محتوای انگلیسی (فیلم، ویدئو، کلاس آنلاین و...) با زیرنویس فارسی است، بدون وابستگی دائمی به سرویس‌های ابری.

</div>

```
صدای داخلی → گفتار انگلیسی → متن → ترجمه فارسی → زیرنویس شناور
```

<div dir="rtl" align="right">

## امکانات

- تبدیل زنده گفتار انگلیسی به متن
- ترجمه خودکار انگلیسی به فارسی
- نمایش زیرنویس به‌صورت Overlay روی سایر برنامه‌ها
- استفاده از صدای داخلی دستگاه به‌جای میکروفون
- پردازش کاملاً On-Device و بدون نیاز به اینترنت (پس از دانلود مدل‌ها)

## حریم خصوصی

پردازش گفتار و ترجمه کاملاً روی دستگاه انجام می‌شود و هیچ صدایی به سرور خارجی ارسال نمی‌شود.

> **توجه:** برای دریافت صدای محتوای در حال پخش، برنامه از قابلیت Audio Playback Capture اندروید استفاده می‌کند.

## مدل‌های هوش مصنوعی

| مرحله | مدل / ابزار |
|---|---|
| تبدیل گفتار به متن (Speech-to-Text) | |
| ترجمه انگلیسی ← فارسی | Marian (آموزش‌دیده برای این پروژه، فرمت ONNX) |

### مدل ترجمه Marian

مدل ترجمه با داده‌های موازی انگلیسی–فارسی آموزش داده شده و برای اجرای بهینه روی Android به فرمت ONNX تبدیل شده است. این مدل به‌صورت مستقل نیز در Hugging Face منتشر شده است: [omid1989ahmadi/marian-en-fa](https://huggingface.co/omid1989ahmadi/marian-en-fa)

| مشخصات | مقدار |
|---|---|
| Architecture | MarianMT |
| Direction | English → Persian |
| Tokenizer | MarianTokenizer |
| Vocabulary | 32,000 tokens |

برای استفاده از مدل خارج از ZirNevis، مستندات و فایل‌های آن را در صفحه Hugging Face ببینید.

## نصب

ZirNevis روی **کافه‌بازار** منتشر شده است:

[دریافت ZirNevis از کافه‌بازار](https://cafebazaar.ir/app/com.zirnevis)

1. برنامه را از کافه‌بازار نصب کنید.
2. برنامه را اجرا کنید و مدل‌های موردنیاز را دانلود کنید.
3. مجوزهای نمایش Overlay و دریافت صدای داخلی را فعال کنید.
4. یک محتوای انگلیسی پخش کنید و ZirNevis را فعال کنید.

## نکات مهم

- تشخیص گفتار فعلاً فقط برای **انگلیسی** و ترجمه فقط در مسیر **English → Persian** است.
- کیفیت تبدیل گفتار به متن به کیفیت صدای ورودی و سخت‌افزار دستگاه بستگی دارد.
- اجرای مدل‌ها به CPU و RAM کافی نیاز دارد و مدل‌ها فضای قابل‌توجهی از حافظه را اشغال می‌کنند.
- دریافت صدای داخلی به نسخه Android و پشتیبانی دستگاه از Audio Playback Capture وابسته است.
- برخی برنامه‌ها اجازه Capture شدن صدای خود را نمی‌دهند.

## سازگاری

ZirNevis برای دستگاه‌های Android طراحی شده است. حداقل نسخه Android موردنیاز در صفحه برنامه در کافه‌بازار مشخص شده است.

## وضعیت پروژه

ZirNevis در حال توسعه است و قابلیت‌ها، مدل‌ها و عملکرد آن ممکن است در نسخه‌های بعدی تغییر کنند.

## مجوز

مجوز برنامه و مدل‌های مورد استفاده، در صورت نیاز، در صفحه هر مدل مشخص می‌شود.
